# frnikho.github.io

To install dependencies:

```bash
bun install
```

To run locally:

```bash
bun run dev
```

To build for production:

```bash
bun run build
```

To run with Docker:

```bash
docker build -t frnikho.github.io .
docker run -p 3000:3000 frnikho.github.io
```

This project uses [Bun](https://bun.sh) and [TanStack Start](https://tanstack.com/start).
